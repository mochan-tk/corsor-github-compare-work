# Interactive Art Piece

This project is an interactive art piece that runs in a browser, featuring a full-screen canvas with a dark background and rainbow-colored ripple effects.

## Project Structure

```
interactive-art-piece
├── src
│   ├── index.html       # Main HTML document
│   ├── styles.css       # Styles for the canvas and body
│   └── app.js           # JavaScript code for ripple effects and interactions
├── package.json          # Configuration file for npm
└── README.md            # Documentation for the project
```

## Features

- Full-screen canvas that responds to user interactions.
- Dark background (#111) with rainbow-colored ripple effects.
- Ripple effects generated on mouse clicks and movements.
- Touch support for mobile devices.

## Setup Instructions

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd interactive-art-piece
   ```

3. Install dependencies:
   ```
   npm install
   ```

4. Open `src/index.html` in a web browser to view the interactive art piece.

## Usage

- Click anywhere on the canvas to create ripples.
- Move the mouse to generate small ripples along the cursor's path.
- Touch the screen on mobile devices to create similar effects.
